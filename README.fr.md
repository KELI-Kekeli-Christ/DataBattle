Prédiction de la fin d’alerte foudre dans les aéroports, Data Battle IA PAU 2026 (équipe FLYKDATA). La méthode du `README.md` est un empilement de modèles XGBoost avec intervalles quantiles. Scripts présents : `app.py`, `model.py`, `model_prediction.py`, `modele_final_prediction.py`, plus `prediction.ipynb` et `data_visualisation.ipynb`.
